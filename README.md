# Analysis Code for NTS-PAG Project

This repository contains the analysis code for the study **“A brainstem pathway underlying vagal modulation of somatic pain and affective states”**  
It includes MATLAB scripts for behavioral and neural data analysis, and Python scripts for tracking of the pupil size.

---

## System Requirements

### Hardware
- Tested on **Windows 11**
- ≥16 GB RAM recommended for neural data analysis
- ≥100 GB disk space for raw data and processed files

### Software
- **MATLAB R2022b** (used for behavior and neural data analysis)
- **Python 3.10** (used for deeplabcut)

### MATLAB Toolboxes and External Dependencies
- **Deep Learning Toolbox** — [https://ww2.mathworks.cn/products/deep-learning.html](https://ww2.mathworks.cn/products/deep-learning.html)  
- **Computer Vision Toolbox** — [https://ww2.mathworks.cn/products/computer-vision.html](https://ww2.mathworks.cn/products/computer-vision.html)


### Python Dependencies
- Python ≥3.10  
- pytorch
- pytables
